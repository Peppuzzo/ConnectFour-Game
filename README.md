# Connect 4 Game 🕹️

A simple, desktop-based implementation of the classic **Connect 4** game built with **JavaFX** and **Gradle**, featuring a clean MVC architecture.

## ✨ Features
* **Interactive Graphical Interface**: Built using JavaFX and custom CSS styling.
* **Game Modes**: Support for standard local gameplay.
* **Build Automation**: Fully managed via Gradle.

---

## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed on your system:
* **Java Development Kit (JDK)** (Java 17 or higher recommended)
* **Gradle** (or you can use the included Gradle wrapper `./gradlew` / `gradlew.bat`)

### Instructions to Run the Project
To build and run the project using Gradle follow these commands:

```bash
gradle build
gradle run
